# V2 版本记录

## v0.11（2026-06-01）

- 在 `V2/项目规范.md` 明确写入自动同步规则：从 v0.11 起，V2 任务默认由 AI 自动完成 `git status -> commit -> push`。
- 约束补充：仅在用户明确要求不提交/不推送，或远端客观阻塞时允许中止，并需记录阻塞原因。

## v0.10（2026-06-01）

- V2 自动造菜链路切换为复用 V1 `generate_auto_dish_idea()`，完整继承“参考传统菜抽取 + 历史去重 + 近10条主食材/口味/做法禁用拦截”逻辑。
- 新增并启用 `V2/dish_idea_memory.jsonl`，默认通过 `AUTO_DISH_MEMORY_FILE=V2/dish_idea_memory.jsonl` 记录 V2 历史创意，避免连续撞“蒜香”等方向。
- 增强 V2 日志：自动造菜时输出“本轮菜系范围 / 本轮参考传统菜 / 历史记忆文件”，便于追溯新菜来源。

## v0.09（2026-06-01）

- 调整豆包模板策略为“仅替换变量位”：模型只返回 `replacements` 数组，程序按模板变量顺序回填，不再允许改写非变量行。
- 新增模板回填函数：无 `{变量}` 的模板文本保持原封不动，含变量行只替换变量片段。
- 修复用户指定约束：`cankao.txt` 中 `文案` 等未含“变量”的行，输出时保持与模板完全一致。

## v0.08（2026-06-01）

- 加强豆包模板改写指令：强制按 11 个分类标签逐段输出，并要求段落间空行，减少“一整段长句”返回。
- 优化分类重排算法：关键词识别加入边界约束，避免把“真实拍摄”等普通短语误识别成“拍摄分类”起点。
- 清洗文案段落中的“部分：”残留前缀，保持 `文案：` 行可读性。

## v0.07（2026-06-01）

- 新增提示词可读性整理：豆包提示词在落盘前按 `cankao.txt` 分类自动重排，并在分类之间保留空行，便于人工阅读与迭代。
- 统一分类解析规则：从模板自动提取分类标签（如“目的/配色/菜名/排版...”），无论模型输出是单段文本还是多行文本，都尽量格式化成分类段落。
- 本地降级模板同样接入该格式化流程，保证最终 `*_豆包提示词.txt` 结构一致。

## v0.06（2026-06-01）

- 对齐 V1 生图重试逻辑：仅在超时类错误时按 `IMAGE_REQUEST_RETRY_COUNT` 重试；非超时错误直接抛出。
- 精简 V2 生图流程：移除“首轮失败后改写精简 prompt 再试一次”的额外分支，避免出现“已出图但日志仍报失败”的误导。
- 增加运行态可观测日志：每轮启动都会打印 `AUTO_GENERATE_DISH_IDEA`、命令行 `--mode`、最终生效模式，便于判断是否真的走了自动造菜。

## v0.05（2026-06-01）

- 修复空 `OPENAI_BASE_URL` 导致的 SDK 连接异常：V2 在未配置网关地址时，显式回退到官方 `https://api.openai.com/v1`。
- 避免 `OPENAI_BASE_URL=`（空字符串）被 SDK 误识别为有效 base URL，进而触发 `UnsupportedProtocol` 并上抛为 `Connection error`。

## v0.04（2026-06-01）

- 修复 V2 生图连接异常：`build_openai_image_client()` 改为与 V1 一致的 OpenAI 客户端初始化方式（不再注入自定义 `httpx.Client`）。
- 实测同机同 key 下，V1 风格调用 `gpt-image-2` 可成功返回图片，确认此前 `Connection error` 主要由 V2 客户端构造差异导致。

## v0.03（2026-06-01）

- 对齐 V1 的 OpenAI 网络策略：`V2/v2_core.py` 中 `HTTP_TRUST_ENV` 默认值改为 `1`，默认继承系统代理与证书环境。
- 更新 `V2/config.env`：`HTTP_TRUST_ENV=1`，避免在当前机器上直连官方 `api.openai.com` 超时。
- 新增连通性排查结论：同机测试下 `trust_env=False` 会 `ConnectTimeout`，`trust_env=True` 可正常返回 `200`。

## v0.02（2026-06-01）

- 修复 `cankao.txt` 占位符替换漏网问题：本地降级模板现在同时支持 `{变量}`、`{变量：说明}`、`{变量，说明}` 三种写法。
- 修复豆包改写结果校验：只校验“变量占位符是否残留”，不再把普通花括号一律判定为失败。
- 解决 `蒜香煎鸡胸肉_豆包提示词.txt` 中“特色行残留 `{变量，...}`”的根因。

## v0.01（2026-06-01）

- 初始化 V2 独立主流程入口 `main.py` 与核心模块 `v2_core.py`。
- 新增自动造菜与手动读取 `dish_name.txt` 双模式。
- 新增基于 `cankao.txt` 模板生成豆包提示词，并接入 `gpt-image-2` 生图输出。
- 新增 `script_logging.py` 与 `config.env` 首批配置（默认 `OPENAI_IMAGE_QUALITY=low`、`OPENAI_IMAGE_COUNT=1`）。
