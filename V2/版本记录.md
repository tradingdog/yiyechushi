# V2 版本记录

## v0.05（2026-06-01）

- 修复空 `OPENAI_BASE_URL` 导致的 SDK 连接异常：V2 在未配置网关地址时，显式回退到官方 `https://api.openai.com/v1`。
- 避免 `OPENAI_BASE_URL=`（空字符串）被 SDK 误识别为有效 base URL，进而触发 `UnsupportedProtocol` 并上抛为 `Connection error`。

## v0.04（2026-06-01）

- 修复 V2 生图连接异常：`build_openai_image_client()` 改为与 V1 一致的 OpenAI 客户端初始化方式（不再注入自定义 `httpx.Client`）。
- 实测同机同 key 下，V1 风格调用 `gpt-image-2` 可成功返回图片，确认此前 `Connection error` 主要由 V2 客户端构造差异导致。

## v0.03（2026-06-01）

- 对齐 V1 的 OpenAI 网络策略：`V2/v2_core.py` 中 `HTTP_TRUST_ENV` 默认值改为 `1`，默认继承系统代理与证书环境。
- 更新 `V2/config.env`：`HTTP_TRUST_ENV=1`，避免在当前机器上直连官方 `api.openai.com` 超时。
- 新增连通性排查结论：同机测试下 `trust_env=False` 会 `ConnectTimeout`，`trust_env=True` 可正常返回 `200`。

## v0.02（2026-06-01）

- 修复 `cankao.txt` 占位符替换漏网问题：本地降级模板现在同时支持 `{变量}`、`{变量：说明}`、`{变量，说明}` 三种写法。
- 修复豆包改写结果校验：只校验“变量占位符是否残留”，不再把普通花括号一律判定为失败。
- 解决 `蒜香煎鸡胸肉_豆包提示词.txt` 中“特色行残留 `{变量，...}`”的根因。

## v0.01（2026-06-01）

- 初始化 V2 独立主流程入口 `main.py` 与核心模块 `v2_core.py`。
- 新增自动造菜与手动读取 `dish_name.txt` 双模式。
- 新增基于 `cankao.txt` 模板生成豆包提示词，并接入 `gpt-image-2` 生图输出。
- 新增 `script_logging.py` 与 `config.env` 首批配置（默认 `OPENAI_IMAGE_QUALITY=low`、`OPENAI_IMAGE_COUNT=1`）。
